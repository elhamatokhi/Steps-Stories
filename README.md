# Steps-Stories

Steps & Stories is a personal travel diary app where you can capture the places you've been, the memories you've made, and the stories behind each step of your journey. Document your adventures, pin locations, add photos, and relive your travels—one step, one story at a time.


## Tech Stack

- **Node.js** & **Express** — Backend and routing
- **EJS** — Templating engine for dynamic HTML
- **Multer** — For uploading blog images
- **File System (fs)** — To save and update project data (JSON file)
